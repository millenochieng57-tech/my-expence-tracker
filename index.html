📘 How MillenMoney Works

1. Balance: Tap yellow card to set your starting money.

2. Add Sale: Type item name, price, qty → Click + Add Item → Add more items if customer bought many.

3. Save: Choose Spent/Income, write note (e.g. "Customer John") → Save. It adds to history & updates balance.

4. Daily Tab: See today's sales grouped by day.
5. Receipts Tab: Full receipts with time.
6. Items Tab: Every single item sold.

🔒 Privacy: Click 🔒 PASS to set your own password. Only you can open app on your device.

📥 EXPORT / 📤 IMPORT: EXPORT saves backup to Downloads. IMPORT brings it back if you change phone/PC. Do EXPORT every week!

💻 INSTALL: Click to install as PC/Mobile app. After 1st online open, it works WITHOUT internet.

⚠️ Data: Data is saved ONLY on your device. We cannot see it. If you delete app without EXPORT, data is lost.
